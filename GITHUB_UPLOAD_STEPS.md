# Publishing this project to GitHub

1. Extract this ZIP on your computer.
2. Open the extracted `triallens-clinical-trial-analytics` folder.
3. Open your existing GitHub repository in a browser and choose **Add file → Upload files**.
4. Drag the *contents* of the extracted folder into GitHub (README.md, app.py, data/, docs/, notebooks/, outputs/, reports/, sql/, src/, tests/, requirements.txt, pyproject.toml, LICENSE and .gitignore). Do not upload the outer folder as one nested directory.
5. Commit the upload to the `main` branch.
6. Keep the existing `triallens-clinical-trial-analytics.zip` at repository root for the Colab notebook's setup cell. After the structured upload, remove the duplicate root-level `Copy_of_TrialLens_Clinical_Trial_Analytics_Colab.ipynb`; the clean Colab notebook now lives under `notebooks/`.

Do not upload `.venv`, `__pycache__`, `.pytest_cache`, credentials, or real patient information.
